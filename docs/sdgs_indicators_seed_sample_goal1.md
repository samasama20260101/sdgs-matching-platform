# 個人向けGI定義文 サンプル（ゴール1: 貧困をなくそう）

作成日: 2026-07-06
位置づけ: `docs/sdgs_impact_dashboard_design.md` §7「AI下書き→運営レビュー」ワークフローの
**工程2（AI下書き）の実物サンプル**。このままレビューにかけられる形式で全ゴール分を量産する。

- ID・構成は公式指標体系（総務省仮訳ベース）に準拠
- `labels.ja` = ダッシュボード表示用の短いラベル（〜25字目安）
- `definition_ja` = AI②のプロンプト入力。**「相談がこういう内容・結末なら該当」が判定できる文**にする
- ⚠️ 全件、運営（SDGs×現場知識）のレビュー・修正が必要な**下書き**です

## レビュー観点（運営向けチェックリスト）

```
□ ラベルはダッシュボードで一目で意味が取れるか（25字目安）
□ definition は「相談の内容・結末」で該当判定できる文になっているか
  （国家統計の言い回し=割合・比率・人口カバー率 が残っていないか）
□ 隣接GIとの境界が明確か（1.3.1 公的制度 vs 1.a.1 民間資源 など）
□ 現場で実際に起きる相談パターンを拾えているか（不足があればGI追加 or 定義拡張）
□ 「該当しやすすぎる」定義になっていないか（何にでも付くGIはカウントの意味を薄める）
```

## 備考

- 1.5.2〜1.5.4、1.a.2 など**国家統計専用で個人相談に対応しない指標は収録しない**
  （設計書§8-5: 全指標の網羅は目標にしない。IDの体系だけ公式に従う）。
- このサンプルの品質で全ゴール分（300〜500件）をAI下書き可能。
  優先整備順の提案: **1 → 3 → 8 → 4 → 10 → 16 → 11 → 2 → 5 → 残り**
  （相談の発生頻度が高い領域から）。
