# v2.0 の設計(実装の正本)

更新: 2026-11-05(#72)。設計の元は代表と詰めた設計キャンバス(10/28〜11/4)と、11/5 の定例の決定。キャンバスと食い違うところは 11/5 の決定が正。
この文書は「v2.0 で何をどう作るか」の正本。今のコードが何をしているかは `docs/service_specification.md`(v2.0 の公開時に書き直す)。

## 1. 骨格

- **1人1アカウント**。同じアカウントで「相談する」と「支える」を切り替える。運営(ADMIN)は相談する顔を持たない
- **パスワードを持たない**。メールに届く 6 けたのコードと Google で入る
- **相談する人に聞くのは、呼び名・年齢・国と地域(市区町村まで、任意)・言語だけ**。氏名・電話・住所・性別・生年月日を持たない
- **入口は「わたし(個人)・会社・地域」**、データは1本(`cases.subject_type`)。国の入口は v2.0 では出さない
- **指標(SDGs のグローバル指標)が背骨**。相談の指標は、本人が選んだもの・AI の候補・運営の確定を分けて持つ(`case_indicators`)
- **言語は ja・en・es**。書体は言語ごとに Noto を切り替える

## 2. 決まり(コードで守る)

| 決まり | 置き場所 |
|---|---|
| 年齢は登録日の年齢を基準日から1年ごとに進める。本人が直したらその日を新しい基準日にする。18歳未満は未成年、15歳以下は保護者の同意が原則 | `src/lib/domain/age.ts` |
| 個人の相談は団体を通して支える。個人の支え手には、会社・地域の相談のうち機微でも18歳未満でもないものだけを出す | `src/lib/domain/visibility.ts` |
| 団体は運営が承認した団体の、今いるメンバーだけが相談を見られる。抜けた日から読めない | 同上 |
| 機微な相談(指標の印・18歳未満)の中身は、団体のメンバーでも2つ目の確認(認証アプリ)を通った人だけ | 同上・`src/lib/domain/sensitivity.ts` |
| 自分の相談・自分の団体が相談した相談は、支える側に出さない | 同上 |
| 支え手は1件の相談に3者まで。最初に選ばれた1者が中心。中心は相談者の同意を得てほかの支え手を招ける | `accept_sos_offer`(DB)・`MAX_SUPPORTERS_PER_CASE` |
| 個人の支え手が申し出るには電話番号の確認(SMS)が要る | `src/lib/domain/visibility.ts` の `canOffer` |
| スコア = Σ(解決した相談に付いた、運営が確定した指標の数 × 対象の人数)。個人の相談は 1、会社・地域の相談は団体が登録した人数。「ありがとう」は別に数える | `src/lib/domain/score.ts` |
| 社会貢献の記録は人に付き、その時の所属を残す。追記だけ(書き換えは DB が断る)。退会したときだけその人の行をすべて消す | `contributions` の trigger |
| 代理登録の引き継ぎコードは読み違えやすい字を使わず、DB にはハッシュだけを置く。30 日・使い切り・5 回失敗で使えなくする | `src/lib/domain/handover.ts` |
| 知らせのメールには、件名にも本文にも相談の中身を書かない | 通知の送り口 |
| AI に渡す文は `maskPii` と `fenceConsultation` を通す。AI は機微を上げる方向にだけ効かせる | `src/lib/ai/*` |
| 支える側の大項目の名前は、相談した人の種類(個人・会社・地域)ごとに依頼者の指標一覧の列D〜F を使う(11/5 岡本さん)。得意なことと絞り込みは「種類 × ゴール」の単位で持ち、名前は表示だけに使う。探す画面は種類を選んでから大項目を選ぶ。個人の支え手の得意なことは会社と地域の分だけ | `src/lib/domain/supportAreas.ts`・`supportAreas.generated.ts`(`scripts/ledger/import-org-intake.ts` が作る) |

## 4. 審査(11/5)

申し込みフォーム(簡単な情報と10項目)→ 運営へのメール → 面談(運営のチェックリスト)→ 承認(管理画面)→ 一覧に載る。2段階に分けない。公開情報との照合は必須にしない。
`organizations.vetting_status`: APPLIED → INTERVIEW → APPROVED(または REJECTED / SUSPENDED)。
