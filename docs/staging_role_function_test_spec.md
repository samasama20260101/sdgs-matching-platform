# Staging ロール別機能仕様・テスト観点

## 目的

Staging環境で、SOSユーザー・サポーター・管理者それぞれの主要機能が意図どおり動くか確認する。

本ドキュメントは、開発メンバーやテスト担当者へ渡して利用するための機能仕様兼テストチェックリストである。

## 対象環境

| 項目 | 内容 |
|---|---|
| 対象 | Staging |
| URL | https://sdgs-matching-platform-git-dev-samasama.vercel.app |
| Supabase Project Ref | `fzawgdmqewmwdqjsqjwt` |
| ブランチ | `dev` |

Productionでは実施しない。
DB変更を伴う確認は、Staging Supabaseでのみ行う。

## 共通前提

- テスト前にStagingへ最新の`dev`がデプロイされていること。
- Stagingのテストユーザーは `docs/test_users_list.md` を参照する。
- テストで作成した相談・メッセージ・団体情報はStagingデータとして残ってよい。
- 個人情報に見える内容は、テスト用の架空データを使う。
- エラーが出た場合は、画面URL・操作内容・入力内容・表示されたエラー文を記録する。

## 合格基準

- ロールごとの主要フローが最低1回ずつ完了する。
- 団体情報と担当者個人情報が画面上で混在して見えない。
- SOSの非公開情報がサポーター画面に不用意に表示されない。
- サポーターOWNERだけが団体情報を編集できる。
- 活動地域の保存でエラーが出ない。
- 管理者がユーザー・団体・地域コードを追跡できる。

# 1. SOSユーザー視点

## 1.1 ログイン・ダッシュボード

### 仕様

SOSユーザーはログイン後、SOSダッシュボードで自分の相談状況を確認できる。

### 確認項目

- SOSユーザーでログインできる。
- `/sos/dashboard` が表示される。
- 表示名であいさつが表示される。
- 地域未設定の場合、プロフィール設定を促す案内が表示される。
- 進行中の相談がある場合、相談カードが表示される。

## 1.2 SOSプロフィール編集

### 仕様

SOSプロフィールは、非公開の連絡先・サポーターに表示される情報・支援提案に使う地域・詳細住所に分かれる。

### 確認項目

- `/profile` を開ける。
- 以下のカードが表示される。
  - `非公開の連絡先`
  - `サポーターに表示される情報`
  - `支援提案に使う地域`
  - `詳細住所`
- `お名前`、`メールアドレス`、`電話番号` が非公開情報として説明されている。
- `ニックネーム` がサポーターに表示される情報として説明されている。
- 地域コードを選択して保存できる。
- 詳細住所は任意・非公開として説明されている。
- 保存後に成功メッセージが表示される。
- 再読み込み後も保存内容が残っている。

## 1.3 相談投稿

### 仕様

SOSユーザーは相談フォームから相談を投稿できる。
Q1〜Q5は必須で、自由記述の「いま何が起きていますか？」も必須。

### 確認項目

- `/sos/hearing` を開ける。
- Q1〜Q5すべてに必須マークが表示される。
- Q1〜Q5のうち未選択がある状態で送信するとエラーになる。
- `いま何が起きていますか？` が未入力の場合エラーになる。
- Q1〜Q5と必須自由記述を入力すると送信できる。
- 送信中にAI分析中の表示が出る。
- 投稿後、結果画面または相談詳細画面へ遷移する。

## 1.4 相談結果・支援申し出

### 仕様

SOSユーザーは自分の相談に対するサポーターからの申し出を確認し、承認または辞退できる。

### 確認項目

- 相談詳細画面を開ける。
- サポーターからの申し出がある場合、団体名で表示される。
- 承認操作ができる。
- 辞退操作ができる。
- 承認後、相談ステータスや表示が変わる。
- 上限数を超える承認ができない。
- サポーター個人名と団体名の表示が不自然に混ざっていない。

## 1.5 メッセージ

### 仕様

マッチ後、SOSユーザーはサポーターとメッセージをやり取りできる。
内部メモはSOSには表示されない。

### 確認項目

- メッセージ一覧が表示される。
- メッセージを送信できる。
- 送信後、画面に反映される。
- サポーター側から送られたメッセージが表示される。
- サポーターの内部メモはSOS画面に表示されない。

## 1.6 サポーター一覧・団体公開ページ

### 仕様

SOSユーザーはサポーター一覧や団体公開ページを確認できる。

### 確認項目

- `/supporters` を開ける。
- サポーター団体が一覧表示される。
- 地域情報がある場合、近い地域の表示・提案が自然に見える。
- 団体公開ページを開ける。
- 団体名、説明文、活動地域、外部リンクが表示される。
- 担当者個人の電話番号や個人住所が公開ページに表示されない。

# 2. サポーター視点

## 2.1 ログイン・ダッシュボード

### 仕様

サポーターは団体に所属する個人アカウントとしてログインし、団体として相談案件に対応する。

### 確認項目

- サポーターOWNERでログインできる。
- `/supporter/dashboard` が表示される。
- あいさつや表示名が団体名中心に見える。
- 対応可能な相談案件が表示される。
- 相談カードにSOSユーザーのニックネームが表示される。

## 2.2 サポータープロフィール編集

### 仕様

サポータープロフィールは、担当者個人情報・団体情報・公開プロフィールに分かれる。
団体情報はOWNERのみ編集できる。

### 確認項目

- サポーターOWNERで `/profile` を開ける。
- 以下のカードが表示される。
  - `あなたの担当者情報`
  - `団体情報`
  - `公開プロフィール`
- `あなたの担当者情報` には担当者個人の項目だけが表示される。
  - 担当者名
  - 表示名
  - メールアドレス
  - 担当者個人の電話番号
  - 部署・所属
  - 外線番号
  - 内線番号
- `団体情報` には団体項目だけが表示される。
  - 団体名
  - 団体代表電話番号
  - 団体所在地
  - 活動地域
- `公開プロフィール` には団体公開ページ向けの項目が表示される。
  - 自己紹介文
  - 公式サイト
  - SNS・外部リンク
- 団体名を保存できる。
- 団体代表電話番号を保存できる。
- 団体所在地を保存できる。
- 活動地域を追加・変更して保存できる。
- 保存後に成功メッセージが表示される。
- 再読み込み後も保存内容が残っている。
- 団体公開ページに公開プロフィールが反映される。

## 2.3 MEMBER権限

### 仕様

サポーターMEMBERは担当者個人情報を編集できるが、団体情報は編集できない。

### 確認項目

- サポーターMEMBERでログインできる。
- `/profile` を開ける。
- `あなたの担当者情報` は表示される。
- `団体情報` は表示されない、または編集できない。
- `公開プロフィール` は表示されない、または編集できない。
- 担当者名・表示名・電話番号・部署などを保存できる。
- OWNER専用操作を直接URLで開こうとしても実行できない。

## 2.4 メンバー管理

### 仕様

OWNERは団体に所属するメンバーを管理できる。

### 確認項目

- `/supporter/members` を開ける。
- 団体メンバー一覧が表示される。
- メンバーを追加できる。
- メンバーの担当者情報を確認・編集できる。
- MEMBERを停止できる。
- 停止したMEMBERを復帰できる。
- MEMBERを所属解除できる。
- 最後のOWNERを解除・停止できない。
- MEMBERにはメンバー管理画面が表示されない、または操作できない。

## 2.5 案件確認・申し出

### 仕様

サポーターはSOS案件を確認し、団体として支援申し出を行う。

### 確認項目

- `/supporter/dashboard` で案件一覧が表示される。
- 案件詳細を開ける。
- 相談内容、SDGs分類、地域情報が表示される。
- 申し出を作成できる。
- 同じ団体から同一案件へ重複申し出できない。
- 申し出後、SOS側に団体名として表示される。
- 承認された申し出はステータスが変わる。

## 2.6 チャット・内部メモ

### 仕様

サポーターはSOSとのメッセージとは別に、内部メモを使える。
内部メモはSOSには表示されない。

### 確認項目

- 案件詳細でメッセージを送信できる。
- SOS側にメッセージが表示される。
- 内部メモを作成できる。
- `自団体のみ` の内部メモが他団体やSOSに表示されない。
- `担当サポーター間` の内部メモが対象範囲どおりに表示される。
- メッセージ表示で団体名と担当者名の見え方が自然である。

## 2.7 解決済み操作

### 仕様

承認順が主サポーターの団体は、案件を解決済みに進められる。

### 確認項目

- 承認済み案件で解決済み操作が表示される。
- 主サポーターのみ解決操作ができる。
- 副サポーターでは解決操作ができない、または表示されない。
- 解決済みにした後、ステータス表示が変わる。
- SOS側の表示が不自然でない。

# 3. 管理者視点

## 3.1 管理者ログイン

### 仕様

管理者は管理画面からユーザー・相談・サポーター・地域情報を確認できる。

### 確認項目

- `/admin/login` からログインできる。
- `/admin/dashboard` が表示される。
- 管理者以外では管理画面へ入れない。

## 3.2 ダッシュボード

### 仕様

管理者は全体状況を確認できる。

### 確認項目

- SOSユーザー数が表示される。
- サポーター数または団体数が表示される。
- 相談件数が表示される。
- ステータス別件数が表示される。
- 問い合わせが表示される。
- 表示データが大きく崩れていない。

## 3.3 SOSユーザー管理

### 仕様

管理者はSOSユーザーを検索・確認し、必要に応じて停止・復帰できる。

### 確認項目

- SOSユーザー一覧が表示される。
- ニックネーム、氏名、メール、地域コードが表示される。
- 地域コードから地域コード一覧へ移動できる。
- ユーザー停止ができる。
- 停止ユーザーがログイン・操作できない。
- 停止解除ができる。

## 3.4 サポーター・団体管理

### 仕様

管理者はサポーター団体と担当者を確認し、必要に応じてアカウントを管理できる。

### 確認項目

- サポーター一覧が表示される。
- 団体名中心で表示される。
- 担当者名と団体名が混ざって見えない。
- サポーター団体を作成できる。
- 作成したサポーターOWNERでログインできる。
- サポーター停止・復帰ができる。
- 注目サポーターの設定ができる。

## 3.5 相談管理

### 仕様

管理者は相談案件を一覧で確認し、問題が起きたときに追跡できる。

### 確認項目

- 相談一覧が表示される。
- `CASE-00001` 形式の管理用番号が表示される。
- SOSユーザー名が表示される。
- ステータスが表示される。
- OPEN、MATCHED、RESOLVED、CLOSED、CANCELLEDの表示が崩れない。
- 廃止済みステータス `IN_PROGRESS` が表示されない。

## 3.6 地域コード一覧

### 仕様

管理者はSOS地域コードとサポーター活動地域を追跡できる。

### 確認項目

- `/admin/regions` を開ける。
- 地域コード、地域名、SOSユーザー数、サポーター団体数が表示される。
- SOS一覧から地域コードをクリックして該当地域へ移動できる。
- 複数地域を持つサポーター団体が地域ごとにカウントされる。
- 全国対応のサポーター団体数が確認できる。
- 不明な地域コードがある場合、未マッピングとして確認できる。

## 3.7 管理者作成

### 仕様

管理者は必要に応じて別の管理者を作成できる。

### 確認項目

- 管理者作成フォームが表示される。
- 必須項目未入力でエラーになる。
- 管理者を作成できる。
- 作成した管理者でログインできる。
- 初回パスワード変更が必要な場合、変更フローへ誘導される。

# 4. 共通・横断テスト

## 4.1 認可・権限

### 確認項目

- 未ログインで `/sos/dashboard` に入れない。
- 未ログインで `/supporter/dashboard` に入れない。
- 未ログインで `/admin/dashboard` に入れない。
- SOSがサポーター専用画面を操作できない。
- サポーターがSOS専用操作を実行できない。
- MEMBERがOWNER専用操作を実行できない。
- 停止ユーザーが操作できない。

## 4.2 メンテナンスモード

### 確認項目

- `MAINTENANCE_MODE=true` で通常ページが `/maintenance` に誘導される。
- メンテ中にAPIが `503` を返す。
- `/api/health` はメンテ中も表示できる。
- `MAINTENANCE_BYPASS_TOKEN` で運営確認用ブラウザだけ通常画面を確認できる。
- 別ブラウザまたはシークレットウィンドウでは引き続き `/maintenance` に誘導される。
- `MAINTENANCE_MODE=false` または未設定に戻すと通常利用できる。

## 4.3 公開ページ

### 確認項目

- トップページが表示される。
- サポーター一覧が表示される。
- 団体公開ページが表示される。
- お問い合わせページが表示される。
- 利用規約、プライバシーポリシーが表示される。

## 4.4 表示名・団体名の見え方

### 確認項目

- SOS画面ではサポーターが団体名中心に見える。
- サポーター画面ではSOSがニックネーム中心に見える。
- 管理画面では追跡に必要な氏名・メール・地域コードが確認できる。
- 団体公開ページに担当者個人の電話番号や住所が出ない。
- メッセージで団体名と担当者名の関係が不自然でない。

## 4.5 データ保持・再読み込み

### 確認項目

- 保存後にページ再読み込みしても入力内容が残る。
- 別ロールで見たとき、見えるべき情報だけ表示される。
- 相談投稿後、ダッシュボード・管理画面に反映される。
- 申し出後、SOS側とサポーター側の表示が一致する。
- メッセージ送信後、双方で表示される。

# 5. 不具合報告フォーマット

不具合を見つけた場合は、以下を記録する。

```text
発見者:
日時:
環境: Staging
ロール: SOS / SUPPORTER OWNER / SUPPORTER MEMBER / ADMIN
URL:
操作手順:
期待した結果:
実際の結果:
表示されたエラー:
入力した主なデータ:
スクリーンショット:
再現性: 毎回 / 時々 / 1回のみ
緊急度: 高 / 中 / 低
```

## 緊急度の目安

| 緊急度 | 目安 |
|---|---|
| 高 | ログイン不能、相談投稿不能、保存不能、権限漏れ、非公開情報の表示 |
| 中 | 主要操作の一部失敗、表示の大きな混乱、検索・追跡不能 |
| 低 | 文言違和感、軽微なレイアウト崩れ、改善提案 |
