# なみあ キャラクター設定メモ

このメモは、明日もsamasama の隠しキャラクターページ `/namia` と、今後のデザイン展開で「なみあ」を思い出せるように残すもの。

## 基本

- 名前: なみあ
- 呼び方: なみあちゃん
- 由来: しずくではなく「なみだ」。困っている人の涙の中に残った、小さな明日の光から生まれた案内役。
- 役割: 困りごとを抱えた人が、誰かにつながる入口まで進めるようにそっと照らす。
- 世界観: かわいさはあるが、軽すぎない。子どもにも親しみやすく、大人にも押しつけがましくない。

## サービスとの関係

- 明日もsamasama は、SOSユーザーがSDGsを意識しなくても相談できる場所。
- なみあは「解決するキャラ」ではなく、「ひとりで抱え込まないための入口を照らすキャラ」。
- 相談文をうまく書けない人、どこに相談してよいかわからない人の気持ちに寄り添う。
- サポーター、NPO、行政、企業へつながるまでの不安をやわらげる案内役。

## 特殊能力: みちあかり

- なみあのおなかの丸い光は、今のロゴと同じ丸い灯。
- ハートなど別の形にはしない。
- この光は「答えを決める力」ではなく、困っている人の言葉や気持ちの中から、次に進むための道を少し明るくする力。
- 名前は「みちあかり」。
- アンパンマンのパンのような直接的な力ではなく、相談する勇気や、支援につながる入口を照らすような力。

## デザイン方針

- 涙型の体、中央の丸い光、やわらかい表情を維持する。
- ブランドロゴの雫/涙の印象を大きく崩さない。
- AIっぽい硬さを避ける。手触り感、ぬくもり、少し不器用な愛嬌を大切にする。
- 子ども向け資料、名刺、PowerPoint、イベント資料にも使えるように背景透明PNGを用意する。
- おちゃめなポーズは歓迎。ただしサービスの信頼感を壊さない程度にする。

## 現在の実装

- ページ: `/namia`
- 隠しページ扱い。ナビゲーションには表示しない。
- 主なファイル: `src/app/namia/page.tsx`
- 画像素材: `public/concepts/mascots/`
- 「はしって、ころん。」の簡易アニメーションは、動きが不安定だったため一旦ページから外している。

## 今後やるなら

- 「走って転ぶ」アニメーションは、CSSだけで無理に動かすより、短いGIF/APNGまたは動画素材として作る方が自然。
- 名刺やチラシ用に、なみあちゃんの一言コピーを複数作る。
- 子ども向け版と大人向け版で表情やコピーを少し変える。
- `/namia` を正式公開する場合は、トップページや `/story` との導線を慎重に設計する。
