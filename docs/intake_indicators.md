# 相談フォームの選択肢(SDGs グローバル指標ベース)

案件登録の相談フォームを、SDGs のグローバル指標ごとの選択肢に作り替える(2026-10-15 依頼者案・ユーザー決定)。
この表が選択肢の**正本**。コードの `src/lib/constants/intakeIndicators.ts` と `messages/<言語>/sdgs.json`(`category` / `indicator`)はこの表から作る。文言を直すときは 3 か所をそろえる(`npm run test:units` が docs・定数・ja の一致を検査する)。

## 決定事項(2026-10-15)

| 項目 | 決定 |
|---|---|
| 旧 Q1〜Q5 | 廃止して置き換える(過去案件の回答はそのまま表示) |
| 選択数 | 0〜3 個。0 個のときは大項目 18「SDGsの隣のお困りごと」を自動で付ける |
| 大項目 18 | 相談者の選択肢には出さない。「SDGs の分類が分からない・分類できない困りごとも、ヒアリングしながら一緒に解決する」という位置づけ |
| 自由記述 | 必須(従来どおり「どんなことに困っていますか」欄) |
| SDGs の決め方 | 選んだ選択肢の大項目で決める(A 案)。AI はタイトル・要約・説明文だけを書き、分類はしない |
| 緊急判定 | 選んだ選択肢の緊急フラグ + 自由記述の緊急語句(従来と同じ仕組み) |
| 相談者側の表示 | 一覧・ダッシュボードのタイルは大項目ラベル(重複は 1 つに)。詳細では選んだ選択肢を表示 |
| サポーター側の表示 | 一覧のタイルは大項目。詳細では選択肢(指標)まで表示 |
| サポーター側のフィルター | 大項目を 1 つだけ選ぶ → その下の選択肢が出て、複数選択で絞り込める |
| 多言語 | 6 言語(ja/en/zh/ko/vi/id)を用意。日本語以外は AI 訳 |
| 選択肢の文面 | 大枠は変えず、誤字・表記ゆれだけ直す(下の「修正箇所」) |
